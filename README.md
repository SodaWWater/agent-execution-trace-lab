# Agent Execution Trace Lab

一个面向 AI 应用开发岗位的本地 Agent 任务执行实验项目。

## 当前状态

项目处于 Phase 2 起始阶段。当前提交只建立个人项目边界和复现入口，尚未声称完成生产能力或量化效果。

## 计划中的具体场景

使用自建的脱敏采购订单样本，完成“异常订单核查与审批摘要”：系统接收核查任务，调用受限工具读取订单和规则，记录每轮决策、工具参数、观察结果与最终摘要。

## 个人实现范围

- Agent 状态机与最大迭代限制
- 上下文选择和工具 JSON Schema 契约
- 路径白名单、参数校验和可控故障恢复
- Execution Trace 持久化与本地展示

Hermes Agent 是源码学习参考，不复制其完整源码，也不把上游能力计为本项目已实现能力。上游版本、许可证和学习边界记录在 `docs/learning-boundary.md`。

## 后续运行入口

实现完成后，README 将补充从干净环境启动、正常任务、故障注入、测试和 Trace 展示命令。没有脚本、输入、命令和原始输出支撑的指标不会写入项目或简历。
