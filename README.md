# Agent Execution Trace Lab

一个基于开源 Agent 项目学习与二次开发的个人任务执行实验。

项目以本地采购订单核查为案例，将一次任务拆分为可观察的决策、工具调用、结果观察和最终摘要，并保留可回放的执行轨迹。

## 项目内容

- 任务状态机与迭代边界
- 上下文选择和工具 JSON Schema 契约
- 路径白名单、参数校验和可控故障恢复
- Execution Trace 持久化与本地展示

Hermes Agent 是源码学习参考，不复制其完整源码，也不把上游能力计为本项目已实现能力。上游版本、许可证和学习边界记录在 `docs/learning-boundary.md`。

项目使用自建样本，不包含真实业务数据。运行命令、测试结果和演示截图均以仓库中可复现的脚本与原始输出为准。
